# 首版手环原型规格

状态：Module 01 已由用户报告通过 ChatGPT 独立验收（PASS WITH NOTES）；Module 02 已授权实施。本文件约束实际原型，构建与运行证据见当前状态和 Module 02 checkpoint。

## 目标与范围

用户在国行小米手环 9 Pro 上打开 Mirra Band，能用中文界面快速辨认学习状态，并用明确的测试模式检查切换、计时与触控。

范围仅包括独立快应用、模拟数据、状态界面、平台能力诊断、RPK 构建与安装交接。无真实 Session 控制、手机业务修改、云端服务、生产发布或后台常驻。

## 产品语义

原型使用显式演示状态，不定义手机正式状态机。正式数据对接时须另行核对 Mirra 当前代码，不能直接把演示名称映射为手机枚举。

| 演示情形 | 第一眼信息 | 计时语义 / 操作 |
| --- | --- | --- |
| 未开始 | 尚未开始学习 | 无专注计时，进入测试状态选择 |
| 启动准备 | 示例第一步动作 | 模拟完成后进入演示专注，不创建手机 Session |
| 专注 | 状态与示例书名 | 仅演示时长，手动切换 / 重置 |
| 休息 | 休息与剩余时间 | 演示倒计时，归零不自动改真实状态 |
| 恢复 | 回到学习的提示 | 不把恢复时间计为有效专注 |
| 未监测 | 当前未监测 | 可展示示例会话时间，但不声称专注已被验证 |
| 断连 | 手机未连接 / 连接未知 | 无实时手机数据，不展示伪造的绿色连接状态 |

学习状态、监测覆盖、连接状态、数据新鲜度是不同维度。切到断连不改写“上次学习状态”为专注；未来失去通信后，最后快照必须带时间与过期提示。

## 导航与界面

从状态首页进入“测试状态”，选择以上情形后立即回到状态展示；“连接信息”显示原型未接入手机与平台探测结果；系统返回回到首页或退出。入口可见且无需长按猜测。

- 抬腕注意顺序：当前状态 → 时间 / 下一步动作 → 示例书名 → 次要操作。
- 所有界面持续展示“测试模式”，样例书名、时间与页码标为模拟数据。
- 沿用手机 Mirra Blue：背景 `#F2F4F7`、文字 `#181A1D`、次级文字 `#626873`、强调 `#6598E8`、主按钮 `#386FBE` / 白字。这些值来自手机现有 Palette，不是新品牌方案。
- 采用矩形 336 × 480 的目标；`designWidth: 168` 作为首个待验证布局参数，不能仅凭物理 DPR 计算所有样式。
- 重点内容不依赖颜色识别，不堆叠多张卡片或复杂图表。超长中文、空书名与 99 小时以上计时需有明确降级。
- 为目标设备设置足够触控区域、内边距与滚动空间，具体尺寸由模拟器和真机确定；不把手机 48dp 直接当 Vela 单位。

## 时间与生命周期

界面刷新次数不作为累计时间；演示时间从锚点计算，倒计时下限为零。隐藏/销毁时清理刷新任务，返回前台重算，重复进入不叠加计时器。系统时间倒退不产生负数或无依据的有效专注。

首版无需持久化演示数据；重新启动回到明确的初始测试状态。用户不会因此丢失手机学习记录，因为原型不拥有这些记录。

## 能力诊断

只读探测 `system.interconnect` 模块加载、连接查询与错误回调；不向手机发送业务命令。仅在 API / 错误码有明确依据时显示具体原因；其余显示“未连接 / 原因未知”或“连接状态未知”，不能从一次失败推断未配对或不兼容。模块加载失败可以报告“通信接口不可用”，保留适当的非敏感错误信息。

原型使用独立演示包名 `com.guanyi.mirra.band.demo` 和本地开发签名。它与正式手机 `com.guanyi.mirra` 不匹配，因此不期待能连通正式 Mirra。探测只能证明 API 在当前环境中的表现，不能解决真实通信条件。

开发交付和真机验收分开记录。RPK 构建成功不能替代真机运行；网页示意图不能当作 Vela 模拟器或手环截图。缺少工具或设备验证时列明 Not Run，不提前宣布兼容。

实施顺序：固定局部 aiot-toolkit 2.0.5 并验证 Node → 原创最小 `.ux` 与原生 JavaScript → 状态/时间模型与检查 → 七种情形和返回流程 → 只读平台探测 → 实际 debug/release RPK 与包内容/签名检查 → 运行截图、安装交接与项目 checkpoint。公开版本信息与 reference 见 [平台核查](research/VELA_FEASIBILITY.md)。

## 真机检查清单（尚未执行）

2. 七种情形均可触控选择；中文、长书名与大时间不裁切主要信息。
3. 倒计时归零、手动重置、退出重开不出现负数或重复刷新。
4. 返回/侧滑退出、息屏后重新打开行为明确，无崩溃。
5. 连接信息如实显示，未监测和断连不被展示为真实专注。
6. 手机 Mirra 继续正常使用；不要求清数据、卸载或重新签名手机应用。
